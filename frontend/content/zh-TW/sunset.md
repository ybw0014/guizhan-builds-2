# 鬼斬構建站 v2 停止服務公告

鬼斬構建站(builds.guizhanss.com)要和大家說再見了。接下來這段時間，我們會逐步關停本站，由鬼斬資源站([resources.guizhanss.com](https://resources.guizhanss.com))接手。停止服務的原因、時間安排和遷移方式都寫在這一頁。

## 為什麼停服 {#why}

本站早已停止功能更新，現在只合併倉庫資訊相關的 PR。鬼斬資源站也不是臨時起意的新專案，而是一直在推進的後繼平台，現在已經基本可以使用了。

另一方面，本站的自動構建依賴 GitHub Actions 的定時任務輪詢倉庫更新，但這個定時任務的觸發時間早就不穩定了，經常出現構建遲遲不觸發的情況。新站基於 Cloudflare Workers，定時任務穩定，也提供更全面的服務。

既然新站已經可用，就沒有必要繼續維護一套老舊且不可靠的基礎設施。我們決定逐步關停本站，把精力集中在新站。

## 停服時間線 {#timeline}

| 日期(北京時間)   | 事項                                                                                  |
| ---------------- | ------------------------------------------------------------------------------------- |
| **2026-10-18 12:00** | 停止接受新專案 PR，關閉自動構建。已有專案的頁面、構建和下載不受影響                    |
| **2026-11-15 12:00** | 全面停服:本站域名跳轉至新站，API 下線。構建儲存(R2)會保留，僅作為後續遷移未遷移專案的資料來源，不再對外提供服務 |

## 如何遷移 {#migrate}

打開新站的匯入頁面，按提示操作即可:[遷移到鬼斬資源站](https://resources.guizhanss.com/project/import/guizhan-builds-v2)

- **單個匯入**:任何 v2 專案都能匯入，不限是不是你的專案。
- **批量匯入**:僅當專案在本站的 GitHub 使用者名稱與鬼斬資源站中某個使用者或組織的識別符一致時，才能批量匯入。名下專案多的作者，建議直接用 GitHub 使用者名稱註冊新站。

## 沒來得及遷移的專案 {#unmigrated}

停服之後，構建儲存(R2)還會保留，但僅作為後續遷移未遷移專案的資料來源。本站不再提供專案頁面、構建列表、構建文件下載或 API 等公共服務。

不過 2026-10-18 之後本站就不再產生新構建了，沒遷移的專案會一直停在最後一次構建的狀態。請各位作者儘早遷移。
