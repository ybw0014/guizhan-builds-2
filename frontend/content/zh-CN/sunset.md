# 鬼斩构建站 v2 停止服务公告

鬼斩构建站(builds.guizhanss.com)要和大家说再见了。接下来这段时间，我们会逐步关停本站，由鬼斩资源站([resources.guizhanss.com](https://resources.guizhanss.com))接手。停止服务的原因、时间安排和迁移方式都写在这一页。

## 为什么停服 {#why}

本站早已停止功能更新，现在只合并仓库信息相关的 PR。鬼斩资源站也不是临时起意的新项目，而是一直在推进的后继平台，现在已经基本可以使用了。

另一方面，本站的自动构建依赖 GitHub Actions 的定时任务轮询仓库更新，但这个定时任务的触发时间早就不稳定了，经常出现构建迟迟不触发的情况。新站基于 Cloudflare Workers，定时任务稳定，也提供更全面的服务。

既然新站已经可用，就没有必要继续维护一套老旧且不可靠的基础设施。我们决定逐步关停本站，把精力集中在新站。

## 停服时间线 {#timeline}

| 日期(北京时间)   | 事项                                                                                  |
| ---------------- | ------------------------------------------------------------------------------------- |
| **2026-10-18 12:00** | 停止接受新项目 PR，关闭自动构建。已有项目的页面、构建和下载不受影响                    |
| **2026-11-15 12:00** | 全面停服:本站域名跳转至新站，API 下线。构建存储(R2)会保留，仅作为后续迁移未迁移项目的数据源，不再对外提供服务 |

## 如何迁移 {#migrate}

打开新站的导入页面，按提示操作即可:[迁移到鬼斩资源站](https://resources.guizhanss.com/project/import/guizhan-builds-v2)

- **单个导入**:任何 v2 项目都能导入，不限是不是你的项目。
- **批量导入**:仅当项目在本站的 GitHub 用户名与鬼斩资源站中某个用户或组织的标识符一致时，才能批量导入。名下项目多的作者，建议直接用 GitHub 用户名注册新站。

## 没来得及迁移的项目 {#unmigrated}

停服之后，构建存储(R2)还会保留，但仅作为后续迁移未迁移项目的数据源。本站不再提供项目页面、构建列表、构建文件下载或 API 等公共服务。

不过 2026-10-18 之后本站就不再产生新构建了，没迁移的项目会一直停在最后一次构建的状态。请各位作者尽早迁移。
